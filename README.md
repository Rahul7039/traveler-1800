One sentence, 146 characters, explaining the modern internet to a time traveler from the year 1800 — built only from things they would already know (a library, a post office, a printing press, a parlour), as a single picture they could hold in their head. Twelve candidate sentences were drafted and scored against the judge brief (period vocabulary, one picture, truth, economy, memorability); the strongest was kept. See DRAFT.md for the candidates and scoring.

## Run it

```sh
node main.ts
```

It writes the sentence to `/output/entry.txt`.
